# FormFill v6

Upload a resume, paste a Google Form link, and FormFill pre-fills the application form.
Two models trained for this project do the work: a fine-tuned BERT NER model reads the resume,
and a fine-tuned MiniLM classifier decides which profile field each form question asks for.
Simple rules handle email, phone, CGPA, links and graduation year. When unsure, it marks the
question REVIEW instead of guessing. You always review the form and click Submit yourself.

## Install
Tested with Python 3.14.3, torch 2.15.0 (CUDA 13.2 build), transformers 5.16.1,
sentence-transformers 6.0.1.
    py -m venv venv
    .\venv\Scripts\Activate.ps1
    pip install -r requirements.txt
    py -m playwright install chromium

(not included, for privacy).

## Limitations
- Google Forms only, English only, text-based resume PDFs (no OCR for scanned resumes).
- File uploads, the "Other" option, date, time, grid and scale questions are not filled.
- Forms that need Google sign-in cannot be read from a link (paste the questions instead).
- Grouped skill options (for example "Programming Language - Java, C, Python") go to REVIEW.
- 10th/12th marks and ID numbers are never filled.
- Real-resume evaluation uses 13 resumes, and fixes were made after error analysis on the same
  resumes, so those numbers are an upper bound (the untuned first run is reported too).
- Skills are the weakest extracted field.

## Privacy
The resume is processed on your computer and nothing is written to disk by the app.
Real resumes and gold files stay in `data/real/`, which is git-ignored.
