# FormFill v6

> 🚀 **Live Demo:** https://formfill-vitap-fallsem202627-dl-project.streamlit.app/

Upload a resume, paste a Google Form link, and FormFill pre-fills the application form.

Two models trained for this project do the work: a fine-tuned BERT NER model reads the resume, and a fine-tuned MiniLM classifier decides which profile field each form question asks for. Simple rules handle email, phone, CGPA, links and graduation year. When unsure, it marks the question **REVIEW** instead of guessing. You always review the form and click Submit yourself.

## Models

Trained weights are not stored directly in this repository because of their size. The application loads the trained models from Hugging Face repositories.

The project uses:

- A fine-tuned **BERT NER model** for extracting information from resumes.
- A fine-tuned **MiniLM field-matcher model** for identifying which profile field a Google Form question is asking for.

## Limitations

- Google Forms only, English only, text-based resume PDFs (no OCR for scanned resumes).
- File uploads, the "Other" option, date, time, grid and scale questions are not filled.
- Forms that need Google sign-in cannot be read from a link; questions can be pasted manually instead.
- Grouped skill options (for example, "Programming Language - Java, C, Python") go to REVIEW.
- 10th/12th marks and ID numbers are never filled.
- Real-resume evaluation uses 13 resumes, and fixes were made after error analysis on the same resumes, so those numbers are an upper bound. The untuned first run is also reported.
- Skills are the weakest extracted field.

## Privacy

The resume is processed by the application and nothing is written to disk by the app.

Real resumes and gold files stay in `data/real/`, which is git-ignored.
